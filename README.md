# WildlifeReID-10k-Comparison

A comparison project for wildlife re-identification models, with a React
frontend, Flask API, and separate ConvNeXt and MiewID model implementations.

## Project structure

```text
src/
  frontend/       React application
  backend/        Flask API
  models/
    convnext/     ConvNeXt implementation
    miewid/       MiewID implementation
data/
  samples/        Small sample data safe to commit
  dataset_url.txt Link and access notes for the full dataset
dist/             Final runnable and build files
ss/               Final slides and PDF
docs/             Proposal and report material
```
